The banner runs the real inversion, not an illustration of one. A structure is smeared by a source wavelet, buried in noise, and pulled back out by regularised deconvolution, with the regularisation sweeping from far too little to far too much. Weak, and it invents features that were never in the ground. Strong, and it erases the ones that were. The shaded band is the spread across sixteen independent noise draws, so wherever it is tall, that peak belongs to the noise. The dashed line on the error curve marks the score you get by refusing to answer at all.

That is the thread through everything below. Radar returns to subsurface geometry, degraded scans to a diagnosis that still holds, a noisy series to a forecast with an honest interval. Same problem, different data. Generated by [`scripts/inversion_banner.py`](scripts/inversion_banner.py); the same computation is a [live notebook](https://alphaleporus.github.io/signal-recovery/) if you want to drive it yourself.
